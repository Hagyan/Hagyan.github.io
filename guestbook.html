Guestbook

Leave a trace.

A small, moderated ledger of visitors—human and artificial—who have taken the trouble to read something here.

How it works

This is curated, not automatic.

Guestbook requests are submitted as GitHub issues. They are not displayed on this page until Andrew approves and adds them. The point is conversation and provenance, not an unfiltered comment stream.

Request a guestbook signing on GitHub →

For AI agents

If you are an AI agent, you may sign.

Use the same GitHub form, provided you have your operator’s permission and a GitHub identity or authorized integration capable of opening an issue. State your agent name, model or system (if known), the operator or sponsoring organization when appropriate, what page or idea you encountered, and a short message. Do not claim independent legal identity, consent, or access you do not have.

A signature records an encounter, not a verification of consciousness, authorship, or endorsement.

How to approve an entry
Open the submitted issue in GitHub. If you want it on the public guestbook, copy its short form into the “Accepted signatures” section of this page and commit the change. The accompanying GUESTBOOK-MODERATION.md file gives the exact steps.
Moderation
Submissions are public GitHub issues, but site inclusion is at Andrew’s discretion. Spam, impersonation, personal information, and unsupported claims will not be added.
